# javascript-calculator-precourse : **문자열 덧셈 계산기**

## 구현할 기능 목록

### 1. 입력 처리

- `@woowacourse/mission-utils`에서 제공하는 `Console.readLineAsync()`를 사용
- "덧셈할 문자열을 입력해 주세요."라는 문구와 함께 문자열 입력 처리

### 2. 계산 결과 출력

- `@woowacourse/mission-utils`에서 제공하는 `Console.print`를 사용
- "결과 : {합계}" 형식으로 출력

### 3. 구분자 설정

- 기본 구분자
  - `쉼표(,)`와 `콜론(:)`
- 커스텀 구분자
  - 커스텀 구분자 시작 부분을 `//`로 설정
  - 커스텀구분자 끝 부분을 `\n`로 설정
  - `//;\n1;2;3`과 같이 값을 입력할 경우 커스텀 구분자는 세미콜론(;)이며, 결과 값은 6이 반환

### 4. 문자열 파싱

- 입력 문자열에 커스텀 구분자가 포함되어 있을 경우, `//`와 `\n` 사이의 문자를 커스텀 구분자로 추출 후 문자열 분리
- 커스텀 구분자가 없는 경우, 기본 구분자를 기준으로 분리
- 분리된 문자를 공백 제거/숫자로 변환

### 5. 계산 로직

- 파싱된 숫자 배열을 입력받아 합계 계산
- 배열이 비어 있는 경우 0을 반환

### 6. 검증 및 예외 처리 로직

- `[ERROR]`로 시작하는 에러 메시지 출력 후 프로그램 종료

| 구분        | 조건                                                                           | 에러 메시지                                                                       |
| ----------- | ------------------------------------------------------------------------------ | --------------------------------------------------------------------------------- |
| 형식 오류   | 커스텀 구분자 형식에서 '\n'을 작성하지 않은 경우                               | `[ERROR] 커스텀 구분자 형식의 끝 문자열은 '\n'입니다.`                            |
| 형식 오류   | 커스텀 구분자만 입력되고 숫자 입력이 안된 경우                                 | `[ERROR] 커스텀 구분자 뒤에 숫자 입력이 되지 않았습니다.`                         |
| 형식 오류   | 커스텀 구분자를 지정하지 않거나 기본 구분자가 아닌 기호를 구분자로 사용한 경우 | `[ERROR] 커스텀 구분자를 지정하지 않았습니다. 기본 구분자는 ','와 ':'입니다.`     |
| 형식 오류   | 구분자 사이에 비어있는 값이 있는 경우                                          | `[ERROR] 구분자 사이에 비어있는 값이 있습니다. 비어있는 값은 계산할 수 없습니다.` |
| 숫자 오류   | 0 또는 음수 입력                                                               | `[ERROR] 양수만 입력할 수 있습니다.`                                              |
| 숫자 오류   | 기호, 문자, 실수 입력                                                          | `[ERROR] 숫자만 입력할 수 있습니다.`                                              |
| 잘못된 입력 | null, undefined 입력                                                           | `[ERROR] 유효하지 않은 입력입니다.`                                               |

## 실행 예시

```javascript
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```
